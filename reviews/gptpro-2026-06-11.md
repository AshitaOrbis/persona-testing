Public-release verdict

Do not market or publish this yet as a safe CI/CD testing gate for arbitrary web apps. The core idea is workable for trusted local usage, but public release should block on at least:

URL/origin/network policy for browser tools.

Prompt-injection and secret-handling warnings.

Runtime schema validation.

Run-level budget/deadline limits.

Reliable structured output parsing.

CLI/docs consistency.

Safer npm publish workflow separation.

A reasonable release posture after fixes would be: “experimental AI-assisted UX testing for trusted targets,” not “safe automated user testing on every deploy” until the agent sandbox and CI semantics are hardened.
